DevFolio — GAURAV SONI
A responsive single-page developer portfolio built with semantic HTML and CSS. No frameworks, no build step — just HTML, CSS, and a live URL.

Live site: https://gauravsoniii12.github.io/Devfolio/

Run locally
Clone the repo and open index.html in any browser:

git clone https://github.com/gauravsoniii12/Devfolio
cd Devfolio
Then double-click index.html. There are no dependencies to install.

Built with
Semantic HTML5 — <header>, <main>, <section>, <footer>
A colour + type system — CSS custom properties (--brand, --ink, --muted)
Flexbox — the header/nav row and the contact links
CSS Grid — the projects section
Responsive design — min-width media queries take the projects grid from 1 column on mobile to 2 at 700px and 3 at 1000px
